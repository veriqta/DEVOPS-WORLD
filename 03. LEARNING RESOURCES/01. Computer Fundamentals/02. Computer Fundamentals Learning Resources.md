# Recommended Learning Order

You do not need to complete every resource listed above.

For a DevOps learning path, use this order:

1. GCFGlobal - Computer Basics
2. Microsoft Learn - Exploring Basic Computer Concepts
3. OpenLearn - An Introduction to Computers and Computer Systems
4. Khan Academy - Computers and the Internet
5. freeCodeCamp - Computer & Technology Basics
6. Crash Course Computer Science
7. CS50 - Hardware
8. PowerCert - Virtualization Explained
9. Dive Into Systems - Selected systems topics
10. Nand2Tetris - Optional deeper study

After completing the core Computer Fundamentals material, continue to:

**Computer Fundamentals → Linux → Networking → Git & GitHub → Bash → Python for Automation → Cloud → Containers → Infrastructure as Code → CI/CD → Kubernetes**
