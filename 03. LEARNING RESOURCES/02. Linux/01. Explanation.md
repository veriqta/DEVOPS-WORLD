## What It Is

Linux is an open-source, Unix-like operating system family built around the Linux kernel.

The Linux kernel manages the core interaction between software and computer hardware, including:

- CPU scheduling
- Memory
- Processes
- Devices
- Filesystems
- Networking
- System resources

Linux distributions combine the Linux kernel with system utilities, package managers, libraries, shells, services, and other software to provide complete operating systems.

Common Linux distributions include:

- Ubuntu
- Debian
- Red Hat Enterprise Linux
- Rocky Linux
- AlmaLinux
- Fedora
- Amazon Linux
- SUSE Linux Enterprise
- openSUSE
- Arch Linux

## Production Notes

Linux should be treated as a core DevOps engineering skill rather than simply a collection of commands.

Production engineers need to understand what happens underneath commands and how Linux manages system resources.

Important production areas include:

- Process management
- Service management
- CPU utilization
- Memory utilization
- Storage capacity
- Disk I/O
- Filesystem management
- Networking
- DNS
- Permissions
- Users and groups
- SSH access
- System logs
- Package management
- Resource limits
- Security
- Performance
- System updates
- Backup and recovery

An engineer should be able to investigate a Linux server systematically rather than immediately restarting a failing service.

For example, when an application becomes unavailable, investigate:

1. Is the process running?
2. Is the service healthy?
3. Is the expected port listening?
4. Is CPU exhausted?
5. Is memory exhausted?
6. Is the disk full?
7. Are permissions correct?
8. Can dependencies be reached?
9. Is DNS resolving?
10. What do the application logs show?
11. What does the system journal show?
12. What recently changed?

Linux troubleshooting skills directly affect an engineer's ability to troubleshoot:

- Docker
- Kubernetes
- Cloud servers
- CI/CD runners
- Databases
- Production applications

## Security Notes

Linux production systems should follow least-privilege principles.

Important security practices include:

- Avoid routine root usage
- Restrict sudo privileges
- Use SSH keys where appropriate
- Protect private SSH keys
- Disable unnecessary services
- Close unnecessary network ports
- Apply security updates
- Use appropriate file permissions
- Protect sensitive configuration files
- Secure service accounts
- Protect credentials and secrets
- Review authentication logs
- Monitor suspicious processes
- Control privileged operations
- Use firewalls where appropriate
- Restrict remote access
- Use secure package repositories
- Audit important system changes
- Rotate credentials where required
- Apply operating-system hardening standards

Never store:

- Passwords
- API keys
- Cloud credentials
- Private keys
- Production secrets

in:

- Shell history
- Scripts
- Git repositories
- Unprotected configuration files
