## Files and Directories

Learn:

- pwd
- ls
- cd
- mkdir
- cp
- mv
- rm
- touch
- find
- locate
- file
- stat

Learn:

- cat
- less
- head
- tail
- grep
- awk
- sed
- cut
- sort
- uniq
- wc
- xargs
- tee

## Users and Permissions

Understand:

- Users
- Groups
- UID
- GID
- chmod
- chown
- chgrp
- sudo
- File permissions
- Ownership
- Least privilege

## Processes

Learn:

- ps
- top
- htop
- kill
- pkill
- jobs
- bg
- fg
- nohup

Understand:

- PID
- Parent processes
- Signals
- Foreground processes
- Background processes
- Zombie processes

## Services

Learn:

- systemd
- systemctl
- journalctl

Understand:

- Services
- Daemons
- Service startup
- Service dependencies
- Failed services

## Networking

Learn:

- ip
- ss
- ping
- traceroute
- dig
- curl
- wget
- ssh
- scp
- rsync

Understand:

- Interfaces
- IP addresses
- Ports
- Sockets
- DNS
- Routing
- SSH

## Storage

Learn:

- df
- du
- lsblk
- mount
- umount

Understand:

- Filesystems
- Partitions
- Mount points
- Disk usage
- Inodes
- Storage capacity

## System Resources

Learn how to investigate:

- CPU
- Memory
- Load average
- Swap
- Disk I/O
- Processes
- Open files
- Resource limits

## Logs

Learn:

- journalctl
- dmesg
- /var/log

Understand how to use logs during troubleshooting rather than restarting services without investigating the failure.

## Package Management

Understand:

- apt
- dnf
- yum
- rpm
- dpkg

You do not need to memorize every package manager.

Understand how packages, repositories, dependencies, installation, upgrades, and removal work.

## Scheduling

Learn:

- cron
- crontab
- systemd timers

## Archives and Compression

Learn:

- tar
- gzip

## Remote Administration

Learn:

- SSH
- SSH keys
- SCP

## Security

Understand:

- Least privilege
- File permissions
- sudo
- SSH security
- Firewalls
- Package updates
- Service exposure
- Authentication
- Logs
- Secrets
- SELinux or AppArmor concepts

## Troubleshooting

A DevOps engineer should eventually be able to investigate:

- Server is unreachable
- SSH is failing
- Service will not start
- Port is not listening
- CPU is high
- Memory is exhausted
- Disk is full
- Application is slow
- DNS is failing
- Permission is denied
- Process keeps crashing
- Package installation failed
- Filesystem will not mount
- Logs are consuming the disk
- Server cannot reach another service

# When You Are Ready to Move On

Do not move on from Linux simply because you memorized commands.

You should be comfortable:

- Navigating a Linux server from the terminal
- Managing files and directories
- Managing users and permissions
- Installing packages
- Managing processes
- Managing services
- Reading logs
- Using SSH
- Troubleshooting basic networking
- Checking CPU, memory, disk, and system load
- Using pipes and redirection
- Searching and manipulating text
- Understanding the Linux filesystem
- Troubleshooting common server failures

Then continue:

**Linux → Networking → Git & GitHub → Bash/Shell Scripting → Python for Automation → Cloud → Docker → Infrastructure as Code → CI/CD → Kubernetes**
